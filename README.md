# TinyRPC

> 基于 C++20 的轻量级 RPC 框架，自实现 TLV 二进制序列化协议，计划支持 epoll 异步 I/O 与 C++20 协程。

---

## 架构设计

框架采用六层分层架构，各层职责独立、可单独测试和替换：

```
┌──────────────────────────────────────────┐
│  6. 服务注册与发现      静态配置 / 可扩展  │  🚧
├──────────────────────────────────────────┤
│  5. Stub / Dispatch     远程调用透明化    │  🚧
├──────────────────────────────────────────┤
│  4. 协议帧层            二进制帧格式      │  ✅ v0.2
├──────────────────────────────────────────┤
│  3. 序列化层            TLV 编码          │  ✅ v0.1
├──────────────────────────────────────────┤
│  2. 线程池              任务调度          │  ✅ v0.4
├──────────────────────────────────────────┤
│  1. 网络 IO 层          epoll + 非阻塞    │  ✅ v0.3
└──────────────────────────────────────────┘
```

- 客户端调用经 **Stub 代理 → 协议帧封装 → 序列化 → 网络层** 发出
- 服务端反向解包：**网络层 → 协议帧解析 → 反序列化 → Dispatch → 执行**
- 序列化层与协议帧层完全解耦，可独立替换为 Protobuf 等其他方案

## 快速开始

### 环境要求

| 工具 | 版本 | 说明 |
|------|------|------|
| CMake | ≥ 3.16 | 构建系统 |
| GCC / Clang | ≥ 9 / ≥ 10 | 需支持 C++20 |
| 操作系统 | Linux（推荐 WSL2） | 后续使用 epoll |

### 构建与运行

```bash
git clone git@github.com:Archer11-q/tinrpc.git
cd tinrpc
mkdir build && cd build
cmake ..
make -j$(nproc)
./test_serializer
```

预期输出 11 项测试全部 PASS。

## 核心特性

### 自实现 TLV 二进制序列化

- 200 行 C++ 实现完整 TLV 编解码，零外部依赖
- 每字段含 Type 标记，读取时校验类型，防止错位解析
- 网络传输统一大端字节序，位运算实现跨平台字节序转换
- 所有反序列化操作均做边界检查、类型检查、长度校验

### `std::optional<T>` 错误处理

- RPC 热路径异常开销不可接受，`optional` 在类型层面表达"可能失败"，成功路径零开销
- 调用方直接检查返回值，无需 try-catch

### 分层解耦

- 序列化层与协议帧层、网络层完全解耦，每层独立编译为静态库
- 后续可单独替换序列化方案而不影响其他层
